How to use this template (don't paste this box)
  1. Copy the Subject line below into a new Outlook email.
  2. Select everything inside the white email area (from "Hi" to the signature), copy it, and paste it into the message body. Formatting, links, and the download-tip picture carry over. If the picture doesn't appear, insert reference/media/download-hint.png with Insert → Pictures.
  3. Replace every [highlighted placeholder], and remove the highlight.
  4. Check the links. They point to the kit's GitHub repository, which is private. Add the instructor as a collaborator, or upload the files to a shared Teams/SharePoint folder and swap in those links.

When to send: at least three weeks before the session, so the instructor has time to prepare and run a dry run.

Key reminders

  • Attendees use their own work accounts, so their screens match each other. You demo from a separate tenant, so yours may look a little different. Say so up front.
  • Exercise 1 runs on attendees' real mail and calendar: debrief on the pattern and never ask anyone to share their screen.
  • Approvals one at a time, never Approve All. Every Cowork output is a draft to review.
  • Exercise 4 (the custom skill) is the centerpiece. If you run long, use the time checks in the facilitator guide, but never cut Exercise 4.
  • If Cowork is down for the whole room for more than 10 minutes, switch to Plan B in the readiness checklist.
